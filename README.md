# Notas & Compases

App de clases de música (3 años, 4–5 años, iniciación a flauta) con calendario mensual, vista semanal y gestión de actividades. HTML/CSS/JS puro, datos en `localStorage`.

## Desplegar en Vercel
1. Sube esta carpeta a un repo de GitHub (o arrastra la carpeta en vercel.com/new → "Deploy").
2. En Vercel: **New Project → Import** → selecciona el repo. No hace falta configurar build command ni output directory (sitio estático).
3. Deploy.

## Local
Abre `index.html` en el navegador, o `npx serve .`
